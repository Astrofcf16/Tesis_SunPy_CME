# Tesis_SunPy_CME
 Análisis de CMEs tipo halo con SunPy - Tesis

## Descripción
Análisis cinemático y volumétrico de CMEs tipo halo
usando datos SOHO-LASCO con Python y SunPy.

## Estructura del repositorio
- 01_descarga_visualizacion.ipynb
- 02_cinematica_cme.ipynb
- 03_volumen_cme.ipynb

## Requisitos
- Python 3.11 o superior
- SunPy
- Astropy
- Matplotlib
