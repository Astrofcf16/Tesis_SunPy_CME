# Tesis_SunPy_CME
 Análisis de CMEs tipo halo con SunPy - Tesis

## Descripción
Análisis cinemático y volumétrico de CMEs tipo halo
usando datos SOHO-LASCO con Python y SunPy.

## Estructura del repositorio
- descarga_imágenes_fits.ipynb
- cinemática_cme.ipynb
- volumen_cme.ipynb

## Requisitos
- Python 3.11
- SunPy
- Astropy
- Matplotlib
